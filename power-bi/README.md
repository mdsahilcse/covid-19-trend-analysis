# Power BI report

The editable Power BI Project is [COVID-19 Trends.pbip](./COVID-19%20Trends.pbip). It includes two report pages, a PBIR report definition, and an import-mode semantic model. The Cases and Deaths pages share country and date selections. Each page has net change, end-date cumulative and peak-day cards, a country comparison line for the trailing seven-day average, a year-to-week-to-day drill chart, and a cumulative Azure Maps visual.

## Open and refresh

1. Generate the processed archive in the repository root.

   ```powershell
   py -3 -m src.pipeline --out data/processed
   ```

2. On Windows, open `COVID-19 Trends.pbip` in a current Power BI Desktop release. If project support is disabled in your installation, enable Power BI Project and enhanced report format under **File → Options and settings → Options → Preview features**, then restart Power BI Desktop.
3. Select **Transform data → Edit parameters**, or open **Transform data** and edit `DataFolder` in **Manage Parameters**. Use the absolute path to this repository's `data\processed` folder, without a trailing slash. The project starts with `C:\covid-19-trend-analysis\data\processed` as its example path.
4. Select **Apply changes** or **Close & Apply**, then **Refresh** if needed. The model imports `countries.csv`, `dates.csv`, and `daily.csv`.
5. To produce a standalone `.pbix`, select **File → Save As**, choose **Power BI Desktop Files (.pbix)**, and save after refreshing.

## Explore the report

- Choose reporting locations from the country slicer and a range of report dates. The report starts with the US and India selected for comparison.
- Hover over the trailing-average line to inspect the daily count and cumulative total for that date.
- Use the drill buttons above the lower-left chart to move from reporting year to Monday-start week to date. The Thursday of each week determines its reporting year, so a week crossing January 1 stays together. Date filters can produce partial weeks.
- The lower-right map uses end-date cumulative counts at the source's representative coordinates. It follows the date slicer and keeps locations outside the country selection visible. Azure Maps visuals require network access and an enabled Azure Maps setting. The [browser dashboard](../dashboard/) includes a map without that dependency.

## Validation

Microsoft's Power BI Report Authoring CLI v0.5.0 validated the PBIP/PBIR project with zero errors and zero warnings. The semantic model definition passed Microsoft's JSON schema, and all four Power Query expressions passed Microsoft's M parser. Microsoft's Tabular Object Model deserialized the semantic model with three tables, two relationships, and eight measures. The Power BI Desktop render and binary `.pbix` export require a Windows Power BI Desktop session. This source was built on macOS.

Recheck the report definition with Node.js 20 or newer.

```sh
npx --yes --package @microsoft/powerbi-report-authoring-cli@0.5.0 powerbi-report-author validate 'power-bi/COVID-19 Trends.pbip'
```
